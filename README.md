# 坦克动荡 · 1v1 闯关对战

一个**零依赖、单文件**的 HTML5 坦克游戏：打开 `坦克动荡-1v1对战.html` 就能玩，不需要安装任何东西。

**在线玩**：
- https://njusimbo.github.io/tank-game/ （GitHub Pages）
- https://b3518992019b464a9ad06b153cfb3baf.app.workbuddy.host （备用线路）

## 两种模式

打开游戏第一屏即可选择：

### 🤖 人机闯关
- 15 关轮换式闯关，每关敌人配置不同（诡术 / 护盾 / 数量 / 铁壁 / 终局五种路线）
- 每通过一关三选一挑技能，9 个技能各占一个定位：
  - 输出向：散射弹幕 / 急速装填 / 穿甲弹头
  - 生存向：装甲强化 / 不死鸟
  - 机动向：涡轮引擎
  - 地形向：弹跳大师 / 穿墙弹（50% 概率穿透钢墙，砖墙照常炸碎）
  - 经济向：磁力吸金
- 自动存档：中途退出会记住进度，回主页点「继续闯关」接着打
- 三档整体难度（轻松 / 普通 / 困难），影响敌人耐久、瞄准与反应

### 👥 双人对战（同屏）
- 两人共用一块键盘、一块屏幕，互相击毁对方得分
- **开局各得 1000 金币**，9 种技能按强弱定价，随意购买、可重复购买升级
- 每局开打前，双方各免费挑选 **1 个已购技能 +1 级**
- 总局数 3 / 5 / 7 / 9 自选，**先到半数即胜**
- （手机端因同屏键盘限制不提供双人，仅保留人机闯关）

## 通用机制

- **草丛藏身**：站进草丛对手就看不见你（贴脸 1.9 格内除外）；但在草里开枪会暴露位置 1 秒，双方规则一致
- 子弹会反弹，砖墙可炸碎，钢墙需要穿墙弹
- 背景音乐与音效独立开关，音量滑杆自由调节（设置会记住）

## 操作

| 动作 | 玩家 1（闯关 / 双人左侧） | 玩家 2（仅双人） |
|---|---|---|
| 移动 | WASD 或 方向键（手机：左下虚拟摇杆） | 方向键 |
| 开火 | 空格 / 鼠标点击（手机：右侧点位） | 回车 |
| 暂停 | P / Esc | — |

## 运行

无需构建。两种方式任选：

1. 直接双击 `坦克动荡-1v1对战.html`（音乐需 `bgm.mp3` 在同目录）
2. 或起个本地静态服务：`python -m http.server` 后访问 `index.html`

浏览器要求：任何现代浏览器（Chrome / Edge / Firefox）。音乐需要先点一下页面才会响（浏览器自动播放策略）。

## 目录结构

```
├── 坦克动荡-1v1对战.html   游戏本体（单文件，约 220KB）
├── bgm.mp3                 背景音乐（2.1MB，外链引用）
├── index.html              落地页（在线部署时的入口，与本体保持同版）
├── favicon.ico             图标
└── kwm转mp3工具.js          酷我 .kwm 解密小工具（Node.js，与游戏运行无关）
```

## 技术说明

纯 HTML + CSS + 原生 JavaScript（严格 ES5），Canvas 2D 渲染，无任何框架与外部依赖。
