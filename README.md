# 坦克动荡 · 1v1 闯关对战

一个**零依赖、单文件**的 HTML5 坦克游戏：打开 `坦克动荡-1v1对战.html` 就能玩，不需要安装任何东西。

## 玩法

- 15 关轮换式闯关，每关敌人配置不同（诡术 / 护盾 / 数量 / 铁壁 / 终局五种路线）
- 每通过一关三选一挑技能，9 个技能各占一个定位：
  - 输出向：散射弹幕 / 急速装填 / 穿甲弹头
  - 生存向：装甲强化 / 不死鸟
  - 机动向：涡轮引擎
  - 地形向：弹跳大师 / 穿墙弹（50% 概率穿透钢墙，砖墙照常炸碎）
  - 经济向：磁力吸金
- **草丛藏身**：站进草丛敌人就看不见你（贴脸 1.9 格内除外）；但在草里开枪会暴露位置 1 秒，双方规则一致
- 三档整体难度（轻松 / 普通 / 困难）
- 背景音乐与音效独立开关，音量滑杆自由调节（设置会记住）

## 操作

| 动作 | 按键 |
|---|---|
| 移动 | WASD / 方向键（手机：左下虚拟摇杆） |
| 开火 | 空格 / 鼠标点击（手机：右侧点位） |
| 暂停 | P / Esc |

## 运行

无需构建。两种方式任选：

1. 直接双击 `坦克动荡-1v1对战.html`（音乐需 `bgm.mp3` 在同目录）
2. 或起个本地静态服务：`python -m http.server` 后访问 `index.html`

浏览器要求：任何现代浏览器（Chrome / Edge / Firefox）。音乐需要先点一下页面才会响（浏览器自动播放策略）。

## 目录结构

```
├── 坦克动荡-1v1对战.html   游戏本体（单文件，约 172KB）
├── bgm.mp3                 背景音乐（2.1MB，外链引用）
├── index.html              落地页（在线部署时的入口）
├── favicon.ico             图标
└── kwm转mp3工具.js          酷我 .kwm 解密小工具（Node.js，与游戏运行无关）
```

## 技术说明

纯 HTML + CSS + 原生 JavaScript（严格 ES5），Canvas 2D 渲染，无任何框架与外部依赖。
